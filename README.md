# Wolfgang Awards Page

A recreation of the Wolfgang Digital awards page.

## How to run

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser

## Libraries used

- **React 19**
- **Tailwind CSS**
- **react-multi-carousel** — blog post carousel
- **react-hook-form + Zod** — contact form handling and validation
- **react-icons** — icon set
- **Vite** — build tool and dev server
